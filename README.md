# Zepto SQL Data Analysis Project

This project is based on a Zepto dataset where I practiced SQL for data analysis.  
The goal was to explore the dataset, clean it, and extract useful insights using different SQL queries.

I created this project as part of my learning in data analytics, and I’ll keep improving it as I learn more.

---

##  Project Overview

The dataset contains product-level information like:
- Product name
- Category
- MRP
- Discount
- Stock availability
- Quantity

Using this data, I performed:
- Data exploration
- Data cleaning
- Business-related analysis queries

---

##  Tools Used

- MySQL
- SQL (Joins, Aggregations, Filtering, Grouping)

---

##  Key Steps Performed

### 1. Data Exploration
- Counted total records
- Checked sample data
- Identified null values
- Found unique categories
- Checked stock availability
- Identified duplicate product names

### 2. Data Cleaning
- Removed products with invalid pricing (MRP = 0)
- Converted price from paise to rupees
- Verified cleaned data

### 3. Data Analysis
Some of the analysis done in this project:

- Top 10 products with highest discount
- High MRP products that are out of stock
- Estimated revenue by category
- Duplicate product analysis

---

##  Quick Insights

- High discounts are limited to specific products
- Premium products are often out of stock
- Revenue is dominated by a few categories
- Duplicate data entries exist
- Pricing inconsistencies required cleaning
